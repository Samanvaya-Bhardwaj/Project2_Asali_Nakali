Phase 1 · Check a medicine

Is this medicine genuine?

Type the code printed on the pack. The system looks it up in all four databases on both PCs and tells you whether it is genuine (Asali), suspicious or fake (Nakali), and why. A mistyped code is corrected automatically. The page has five parts, listed in the bar above.

1

Enter the code

Use this to start a check. Type a code, barcode or batch number and press Check this code, or click one of the examples.

Examples to try

Try a mistake: MED-ASAL1-OO1 or a batch number like BATCH-A001 still finds the right product. Any product registered on the Databases page can be checked here too.
