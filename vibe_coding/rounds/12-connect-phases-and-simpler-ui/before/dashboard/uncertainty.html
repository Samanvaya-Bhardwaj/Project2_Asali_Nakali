Phase 2 · Integration under uncertainty

The same pack, recorded four ways

A pharmacist types a smudged serial. A phone camera reads a label through glare. A clerk re-keys a dispatch note; a citizen types a code into a complaint form. This page links those imperfect records back to the registry, cleanses the silos, and keeps every counterfeit signal intact.

6 · Insert, modify, delete

Change the data and watch the answer change

Each test writes through the same explorer operation endpoint as the Explorer page, so the change lands in the real silo. The write response already carries the matcher's reading of the row. Every test can be reverted.
